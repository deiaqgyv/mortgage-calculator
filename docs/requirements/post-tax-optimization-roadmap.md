# 后续优化任务与执行顺序

## 优先级原则

先完成用户能直接使用、且会影响所有国家页面的产品核心闭环；再补导出、分享和可审计来源；最后处理 SEO、视觉和跨国家回归。每个步骤必须通过 lint、typecheck、测试和生产构建后才能进入下一步。

## 执行顺序

1. **核心计算闭环（P0）**
   - 完整摊销表查看与下载
   - 额外还款方案的本金、利息、期限变化
   - 多方案对比
   - CSV 导出，防止公式注入
   - 计算输入序列化与分享链接

2. **可审计结果与 PDF（P0）**
   - PDF 导出
   - 计算公式、复利/舍入口径、来源日期
   - 税费、保险、贷款成本分栏
   - 国家和本地法律/财务免责声明

3. **加拿大官方登记费边界（P1）**
   - Saskatchewan、Yukon、Northwest Territories、Nunavut
   - 明确“土地转让税”和“土地登记费”不是同一税种
   - 对无法形成稳定官方公式的数据改为人工输入/提示

4. **国际 SEO 与结构化数据（P1）**
   - canonical、双向 hreflang、x-default
   - 国家级 URL 与 sitemap
   - SoftwareApplication、FAQPage、BreadcrumbList
   - 分享结果页 noindex,follow

5. **数据治理与最终回归（P1）**
   - 统一来源登记、effectiveFrom、reviewedAt
   - 结果页显示数据版本和适用条件
   - 六国、所有税务分支、导出和分享的端到端回归

## 不纳入自动精确计算的内容

- 没有稳定官方全国税率的美国地方房产税和房屋保险；继续使用用户输入。
- 无法从官方来源形成唯一公式的地方登记费；展示官方规则摘要并要求核验。
- 贷款机构产品费率、借款人保险报价、提前还款罚金；作为用户输入或明确排除项。
